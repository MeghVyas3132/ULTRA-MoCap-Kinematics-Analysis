KEY IMPLEMENTATION RULES

1. NORMALIZATION (Step 1):

   ❌ WRONG: scheduler.step() after epoch
   ✅ RIGHT: scheduler.step() after batch (OneCycleLR only)

   for epoch in range(num_epochs):
       for batch in train_loader:
           loss.backward()
           optimizer.step()
           scheduler.step()  # ← Per batch!

3. AUGMENTATION (Step 6):
   ❌ WRONG: augmenter(test_data)  -- ruins test set
   ✅ RIGHT: augmenter(train_data) -- training only

================================================
TROUBLESHOOTING
================================================

Problem: "AttributeError: module has no attribute 'EMGConformer'"
Solution: Make sure emg_improvements.py is in same directory and imported:
  from emg_improvements import *

Problem: "RuntimeError: CUDA out of memory"
Solution: Reduce batch size or d_model
  --batch-size 64 (vs 128)
  --d-model 96 (vs 128)

Problem: "Early stopping triggered at epoch 2"
Solution: Learning rate too high, reduce or use warmup
  Default OneCycleLR includes 30% warmup, should fix this

Problem: "Accuracy worse than baseline"
Solution: Check normalization is fitted correctly
  normalizer.train_mean should be (1, 1, C), not None

Problem: "TTA not improving accuracy"
Solution: Normal for some subjects. Average improvement is +2%
  Try more augments: --n-augments 16
